# PodcastBox web

Next.js interface for the local brief. Run instructions, architecture, and licences are in the repository README.

```bash
npm install
npm run dev
```

The dev server listens on port 43123 and proxies `/api` to the API on port 8742.

Fonts (Fraunces, Inter, and JetBrains Mono) are installed from npm and bundled with the app.
